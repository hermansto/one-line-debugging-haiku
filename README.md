One haiku about debugging — 5-7-5 syllables, three lines, plain text.

```
Logs scroll past midnight
one breakpoint holds the whole truth
it was a typo
```

`main.ts` (Node, stdlib only) writes exactly those three lines to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`) and reads it back to verify an exact match.
